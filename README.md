# guess-number

我的第一个 C 语言项目：控制台猜数字游戏。

## 功能

程序随机生成一个 1~100 的整数，玩家反复输入猜测，程序提示"大了"或"小了"，
直到猜中，并输出总共猜了几次。

## 怎么编译运行

需要先安装 GCC（MinGW-w64）。在项目目录下打开终端：

```bash
gcc main.c -o guess
./guess
```

如果运行时中文显示乱码，先在终端执行：

```bash
chcp 65001
```
